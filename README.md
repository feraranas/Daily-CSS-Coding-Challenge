60 day CSS Coding Challenge

To run any of this examples, move to the directory 'Day#', and run Live Server in VSC.</br></br>

<h3>2024-tailwind</h3>

If you're developing on top of this, run:

```bash
npm install
```

then:

```bash
npx tailwindcss -i ./Days30-60/<Day#>/input.css -o ./Days30-60/<Day#>/output.css --watch
```
